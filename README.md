# ⚓ Marine Engineer Study Hub

မင်္ဂလာပါ! ကျွန်တော့်ရဲ့ Technical Study Hub မှ ကြိုဆိုပါတယ်။ ကျွန်တော်က **Saw Thit Aung** ဖြစ်ပါတယ်။ လက်ရှိမှာ **Uniteam Marine** နဲ့အတူ တာဝန်ထမ်းဆောင်နေတဲ့ သူ တစ်ယောက်ဖြစ်သလို၊ နည်းပညာနဲ့ Web Development ကို စိတ်ဝင်စားသူတစ်ယောက်လည်း ဖြစ်ပါတယ်။

## 🚢 About The Project

ဒီ Website ကို ကျွန်တော်တို့ Marine Engineer တွေ၊ အထူးသဖြင့် COC စာမေးပွဲ ဖြေဆိုမယ့် ညီအစ်ကိုတွေအတွက် စာကျက်လို့ အဆင်ပြေအောင် laptop နဲ့အတွက် အလွယ်တကူ လေ့လာလေ့ကျင့်နိုင်ဖို့ ရည်ရွယ်ပြီး တည်ဆောက်ထားတာပါ။

### What's Inside?

- **MEK Knowledge:** Marine Engineering Knowledge ဆိုင်ရာ အမေးအဖြေများကို လေ့လာနိုင်ပါတယ်။
- **Customizable:** ကိုယ်တိုင်လည်း မေးခွန်းအသစ်များကို "မေးခွန်းစီမံမည်" Tab တွင် ထည့်သွင်းနိုင်ပါတယ်။[cite: 5]

## 💻 Tech Stack
